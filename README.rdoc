Add below lines in database.yml:
 - encoding: utf8mb4
 - collation: utf8mb4_bin

Background jobs running:
 - run redis server with the command `redis-server`
 - run all queue includes default `QUEUE=* rake resque:work`
 - run rescue scheduler `rake resque:scheduler`

Debugging Tools:
 - pry gem usage: call binding class pry function
 - eg: def rhombus; binding.pry end
